# Golank Silver — Digital Contact Page

A lightweight, responsive digital contact card for Golank Silver, built as a static GitHub Pages site.

## Included

- Ivory / pearl background with silver bevel-inspired surfaces
- Concentric-ring details and a layered silver wave motif
- Responsive contact actions: call, WhatsApp and email
- Contact details with copy-to-clipboard controls
- Google Maps directions for the Zaveri Bazaar address
- Downloadable vCard (golank-silver.vcf)
- No app-download section or framework build step

## Deployment

The site is plain HTML/CSS/JavaScript. In the repository settings, select **Pages → Build and deployment → GitHub Actions**. The included workflow deploys the root directory on every push to main.

No bundler, package manager, or server is required.
